# Weather icons (small flash)

- Source: Iconify `material-symbols` (https://icon-sets.iconify.design/material-symbols/)
- Format: LVGL `LV_COLOR_FORMAT_A8` @ 32x32 (~1024 B each)
- Unique assets: 14 (night 70-75 share clear_night; dry/humid reuse)
- Total pixel data: ~14336 bytes (+ descriptors)
- UI applies `image_recolor` from `wx_icon_style_for_hko()`
